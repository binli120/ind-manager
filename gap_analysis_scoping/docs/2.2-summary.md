## Technical Notes

### Why JSON Instead of Excel?
- Excel parsing library (xlsx) had installation issues with Tiptap registry authentication
- JSON template (`2.6.2-summary.json`) provides same structure
- Documented Excel structure for future implementation
- POC focuses on validation logic, not file format parsing

### Rule Extraction Logic
The parser automatically generates rules based on template fields:
1. Detects field presence in template
2. Creates content_presence rule for the field
3. Creates format_requirement rules based on field type
4. Assigns severity based on field importance
5. Provides actionable remediation hints

### Extensibility
Adding new fields is straightforward:
1. Add field to JSON template
2. Update `extractValidationRules()` method
3. Define validation rules for the field
4. Document in TEMPLATE-STRUCTURE.md

## User Experience Flow

### Acknowledging an Issue

1. User clicks "Acknowledge" button on indicator
2. Modal dialog appears with:
   - Issue details (rule name, description)
   - Reason textarea (required)
   - Cancel/Acknowledge buttons
3. User enters reason (e.g., "Will be addressed in next revision")
4. User clicks "Acknowledge"
5. Indicator updates visually:
   - Grayed out appearance
   - "✓ Acknowledged" badge
   - Remains visible but de-emphasized

### Dismissing an Issue

1. User clicks "Dismiss" button on indicator
2. Modal dialog appears with:
   - Issue details
   - Reason textarea (optional)
   - Cancel/Dismiss buttons
3. User optionally enters reason (e.g., "Not applicable for this submission type")
4. User clicks "Dismiss"
5. Indicator animates out and is removed from view

### Reviewing Dismissed Items

1. User clicks "Dismissed Items" button in toolbar
2. Panel slides in from right side showing:
   - "Dismissed" section with count
   - "Acknowledged" section with count
   - Each item shows:
     - Rule name
     - Reason (in quotes)
     - Timestamp
     - "Restore" button
3. User can restore any item by clicking "Restore"
4. Restored item reappears in editor as active indicator

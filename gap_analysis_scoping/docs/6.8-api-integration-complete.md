### Debounce Configuration

- **Delay**: 2000ms (2 seconds)
- **Trigger**: Content change in editor
- **Behavior**: Cancels previous timer on new change
- **Purpose**: Prevents excessive API calls during typing

### Indicator Grouping

Gaps are grouped by section ID (e.g., "2.6.2.1") for better organization:

```javascript
function groupGapsBySection(gaps) {
    const grouped = new Map();
    gaps.forEach(gap => {
        const sectionId = extractSectionId(gap.ruleId);
        if (!grouped.has(sectionId)) {
            grouped.set(sectionId, []);
        }
        grouped.get(sectionId).push(gap);
    });
    return grouped;
}
```

## Usage

### Parse Excel Template
```typescript
import { TemplateParser } from '@/gap_analysis_scoping/features/validation/template-parser';
import * as fs from 'fs';

const parser = new TemplateParser();
const fileContent = fs.readFileSync('template.xlsx');
const ruleSet = parser.parseExcelTemplate(fileContent);

console.log(`Extracted ${ruleSet.rules.length} rules`);
console.log(`Template: ${ruleSet.name}`);
```

### Template Detection Logic
1. Read Excel workbook from buffer
2. Get first sheet
3. Convert to 2D array
4. Check for "Section" column header
5. If found: structured template
6. If not: try key-value pairs
7. Extract appropriate fields
8. Generate validation rules
